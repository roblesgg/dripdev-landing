La web de **DripDev**: quién hay detrás, qué productos hay y cómo contactar. Los productos se presentan en un carrusel 3D que puedes girar.

## Qué tiene

- **Portada** con la marca y el lema.
- **Carrusel 3D** con cada producto de DripDev y su estado.
- **Sobre mí y contacto.**

## Hecho con

Next.js y React, React Three Fiber para el 3D y Framer Motion para las animaciones. Publicada en Vercel.
